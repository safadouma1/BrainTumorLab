Import MRI

NIfTI (.nii / .nii.gz) or a .zip containing one DICOM series per sequence. FLAIR is required; all sequences are resampled to the FLAIR grid and to 1 mm. The full AI analysis (segmentation + grade) starts automatically and needs the 4 sequences. Best results on skull-stripped images, like BraTS.
